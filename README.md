# WorkApps

## Descripción
WorkApps es un proyecto diseñado para facilitar el acceso a herramientas y aplicaciones desde el navegador.


## Para Firefox 
1. ir a Configuración
2. Inicio
3. Nuevas ventanas y pestañas
4. Página de inicio y nuevas ventanas
5. Agregar nueva página:
   - [WorkApps en GitHub Pages](https://wilberth-cl.github.io/workapps/) https://wilberth-cl.github.io/workapps/


## Para GoogleChrome 
1. ir a Ajustes
2. Al iniciar
3. Abrir una página específica o un conjunto de páginas
4. Agregar nueva página:
   - [WorkApps en GitHub Pages](https://wilberth-cl.github.io/workapps/) https://wilberth-cl.github.io/workapps/
